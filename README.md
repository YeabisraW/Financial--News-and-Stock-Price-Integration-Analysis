# Financial News and Stock Price Integration Analysis

This project integrates financial news sentiment with stock price analysis to explore correlations, visualize trends, and compute technical indicators.

## Features

- Data collection and preprocessing
- Exploratory Data Analysis (EDA)
- Technical indicator calculations
- Sentiment analysis of news data
- Correlation analysis between sentiment and stock returns
- PyNance integration for automated stock data analysis

## PyNance Integration

We now use PyNance to fetch stock data and compute key metrics such as daily returns and 30-day annualized volatility.
